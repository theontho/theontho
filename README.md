# Hey, I'm Theo 👋

I build CLI tools, developer templates, and small utilities — mostly in **Python**, **TypeScript**, **Rust**, and **Swift**.  
My projects span bioinformatics, AI/LLM tooling, hardware automation, and data engineering.
